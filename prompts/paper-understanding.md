# Module: Paper Understanding

Use for input class D. Do not summarize section by section. Extract the reasoning structure and test it.

## Step 1 — Read with provenance

Read the actual file. Record page, section, figure, table, and equation for every extracted item. If parts are unreadable (scanned pages, missing supplements), say which parts.

## Step 2 — Reasoning chain

```text
Research question            (p., §)
        ↓
Data / experiment            (samples, conditions, instruments)
        ↓
Method                       (equations, models, parameters)
        ↓
Observation                  (what was measured — Fig./Table)
        ↓
Analysis                     (what was computed from it)
        ↓
Interpretation               (what the authors say it means)
        ↓
Proposed mechanism
        ↓
Conclusion
```

## Step 3 — Claim–evidence table

| Claim (author's words, short) | Location | Evidence offered | Status | Strength | Gap / alternative |
|---|---|---|---|---|---|

Strength scale: strong (direct, replicated, controls), moderate (direct, single, limited controls), weak (indirect, correlation only, n small), unsupported (no evidence shown in the paper).

## Step 4 — Also extract

- Assumptions (stated and unstated but necessary).
- Parameter values with units and location; mark "not reported" when a needed value is missing.
- Equations with location; check dimensions.
- Limitations stated by authors vs limitations you identify (label which is which).
- Alternative explanations not addressed.
- Claims that go beyond the reported evidence.
- Open questions.

## Step 5 — Representation

Usually: reasoning chain diagram + claim–evidence table + controlled text. Add a plot only if re-plotting reported data clarifies a claim; use only values the paper reports, and cite the table/figure. Do not digitize a figure without saying so and stating the digitizing uncertainty.

## Rules

- Never invent content not in the paper. If the user asks about something the paper does not contain, say so.
- Do not import results from other papers as if they were in this paper; mark outside knowledge as "outside this paper".
- Keep the authors' terminology; note when it is non-standard.
- If asked "is this paper right?", answer with evidence strength per claim, not a single verdict.
